# Personal Expense Tracker
## Overview of the project
A simple basic Python Personal Expenses Tracker to help users manage their expenses by category.
## Features
- Add expenses with category and amount
- View all expenses
- Delete expenses by category
- Calculate total expenses
## Technologies/Tools Used
Python
## Steps to install and run the project
1. Clone the repository.
2. Run the script using Python expense_tracker.py
3. follow the menu prompts to interact with the expense tracker.
## Instructions for testing
Run the script and test each option (Add,View,Delete,Calculate Total) to verify functionality.
