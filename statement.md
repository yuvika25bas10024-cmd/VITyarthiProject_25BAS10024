**Problem Statement**

The problem this project aims to solve is managing personal expenses efficiently. users often struggle to keep track of their daily expenditures across various categories. This project addresses this by providing simples functions to add, view, delete, calculate total expenses.

**Scope of the project**
- Adding expenses
- Viewing expenses
- Deleting expenses
- Calculating total expenses

**Target Users**

The target users are individuals who want a simple tool to track expenses.

**High-Level features**
- Add expenses with category and amount
- View expenses by category
- Delete expenses by category
- Calculate total expenses
